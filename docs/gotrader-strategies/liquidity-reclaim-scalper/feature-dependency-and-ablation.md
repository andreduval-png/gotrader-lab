# Feature Dependency And Ablation

The mandatory chain is external objective -> opposite-side raid -> directional
displacement -> IFVG reclaim -> entry geometry. Dealing-range, session, and HTF
bias are optional filters. Entry, invalidation, and target geometry are
inseparable for a candidate.

Removing the objective or raid changes the strategy family and is not a valid
ablation. Disabling optional context, comparing registered geometry models, or
changing an IFVG freshness requirement is a valid separately identified
research configuration. Frozen profiles are never toggled in place.
