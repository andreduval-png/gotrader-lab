# Video Rule Extraction

## Source Supported

- A higher-timeframe external-liquidity objective supplies direction.
- Price raids opposite-side local liquidity before continuation.
- Directional displacement follows the raid.
- An imbalance/IFVG reclaim supplies confirmation and a retracement entry area.
- Invalidation is structural and the native target is external liquidity.

## Existing Canonical GoTrader Interpretation

- Phase 2A liquidity-pool and liquidity-sweep facts represent objectives and raids.
- Phase 2A displacement facts represent directional displacement.
- Phase 2A FVG lifecycle facts and the accepted IFVG adapter define inversion/reclaim semantics.
- Canonical session, dealing-range, and HTF-bias facts provide optional context.
- BT2 owns fills, ambiguity, costs, and outcomes.

## Implementation Inference

Deterministic state names and transition identities are implementation
structure, not video claims. A single entry, stop, and target are emitted for
BT2 compatibility; staged exits remain unimplemented.

## Research Parameters

Timeframes, target/raid category, raid penetration, displacement threshold,
IFVG freshness, entry/retracement, stop/buffer, optional target overlay, session,
bias, dealing-range policy, minimum R:R, and setup/entry age are parameters.

## Unresolved

The source does not establish a universal killzone, displacement threshold,
raid penetration, IFVG mitigation percentage, minimum R:R, partial-exit model,
or winning parameter combination. V1 does not hardcode those claims.
