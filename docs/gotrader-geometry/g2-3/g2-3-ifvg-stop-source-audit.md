# IFVG Stop Source Audit

V1, frozen v3, and research-only v4 all inherit the same base geometry: midpoint entry, distal IFVG edge, and `max(recent average range * 0.03, gap size * 0.02, 0.01)` buffer.

Classification: `ACCEPTED_PROFILE_POLICY` implemented as a legacy deterministic heuristic. The repository does not contain accepted IFVG source lineage authorizing a swept extreme, displacement origin, or arbitrary swing as a replacement stop.

Accordingly, G2.3 retains the existing stop. A wider structural alternative is source-blocked until a separately governed policy proves deterministic precedence. No stop widening was implemented.
