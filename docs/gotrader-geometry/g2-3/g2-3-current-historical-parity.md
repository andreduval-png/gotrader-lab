# Current/Historical Parity

Current and historical IFVG use the same midpoint entry, distal-edge-plus-buffer stop, prior-swing target, symbol risk policy, and retracement-limit lifecycle helper.

Live assessment fails closed for `STOP_DISTANCE_TOO_SMALL` and `ENTRY_MISSED`. Historical assessment uses the same producer eligibility and then waits for a future entry touch before outcome scoring. BT2 receives no request when canonical geometry is invalid; valid levels remain unchanged.

Heavy certified-history characterization was not run while the active local runtime was operating.
