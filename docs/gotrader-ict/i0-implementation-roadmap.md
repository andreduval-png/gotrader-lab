# I0 Implementation Roadmap

I0 authorizes no strategy implementation. Each wave requires its own authorization, isolated branch, immutable
identities, focused tests, full regression, acceptance commit, and governance update.

## I1 - Canonical Fact Ownership

Choose canonical owners for swings, liquidity, imbalance, blocks, dealing range, session, and structure. Add parity
adapters for legacy suite helpers. Do not change frozen strategy outputs.

Exit gate: duplicate map complete, parity fixtures green, no consumer behavior change.

## I2 - Strategy Contract And Registry V2

Implement the complete model contract defined by I0 and register accepted-unintegrated LRS without adopting it at
runtime. Represent context, recognition, confluence, and strategy entries as different types.

Exit gate: impossible to register recognition as executable strategy; all entries identity-bound.

## I3 - Missing High-Value Composite Models

Specify and implement only source-defined composites: OTE, Breaker+FVG, mitigation, and IRL/ERL delivery. Start with
one narrow model, not a batch.

Exit gate: causal detector, native geometry, canonical adapter, BT2 parity, no parameter search.

## I4 - Session And Gap Models

Define Judas, NDOG/NWOG, TGIF, and complete AMD/Power-of-Three semantics from authoritative source packets.

Exit gate: timezone/open identity and holiday/session edge cases proven.

## I5 - Market Maker And 2022 Coverage

Disambiguate ICT 2022, MMBM, MMSM, and MMXM. Reuse C1/C1.1 and S1 context; do not fork narrative or SMT engines.

Exit gate: model definitions are non-overlapping and independently testable.

## I6 - Charter Models

Proceed only after the 12-model definition packet is accepted. Implement one model per slice.

Exit gate: source fidelity, duplicate check, BT2 contract, and explicit taxonomy classification.

## I7 - Coverage Freeze

Re-run the complete inventory, canonical fact parity, strategy adapters, BT2, provenance, Results source-of-truth,
readiness evidence, typecheck/build, and browser gates. Freeze exact identities and unresolved limitations.

Exit gate: every advertised model is either implemented with evidence or visibly unavailable; no placeholder can
appear as an active strategy.

## Priority Decision

Before adding models, complete product-integrity work already identified for Results source-of-truth and immutable,
cycle-bound simulation-runbook evidence. Strategy expansion on top of ambiguous presentation/evidence would make
coverage look broader without making it more trustworthy.
