# I0 Concept Versus Strategy Taxonomy

| Type | Owns | Cannot own | Examples |
| --- | --- | --- | --- |
| Primitive fact | One timestamped causal observation | Eligibility, geometry, edge | swing, FVG, displacement, opening gap |
| Derived context | Relations among facts | Standalone trade evidence | liquidity path, PD hierarchy, dealing range |
| Time filter | Eligibility window only | Direction or geometry | killzone, session, macro |
| Higher-order framework | Market narrative/state | Candidate unless separately modeled | AMD/PO3, MMXM, C1/C1.1 |
| Recognition | Human-readable pattern label | Evidence, readiness, promotion | universal recognition, generic scalp |
| Confluence profile | Support/block policy | Standalone opportunity by default | Grinch, optional/opposing SMT |
| Entry model | Setup and native geometry intent | Fill/outcome mechanics | IFVG, OTE if fully specified |
| Complete trading model | Ordered state, direction, geometry, expiry | Simulator or execution authority | Silver Bullet, Turtle Soup, LRS |
| Strategy variant/profile | Versioned parameter/policy identity | Silent mutation of base model | IFVG v2-v4, raid v2 |
| Canonical adapter | Lossless candidate translation | Inventing levels or blockers | accepted BT3/LRS adapters |
| BT2 | Fills, costs, ambiguity, outcomes, ledger | Strategy semantics | simulator and outcome scorer |
| Presentation | Rendering immutable records | Recalculation or authority | Current Read, Results, Advisor |

## Required Classifications

- Breaker Block and Mitigation Block are facts. A separately sourced sequence may become a model.
- OTE is a retracement concept plus potential entry model; the current registry row is a placeholder.
- PD Arrays are context. "Generic PD Array execution" is not a model until it has unique causal rules.
- Killzones, ICT macros, NDOG, and NWOG facts are time/context inputs; models using them require separate IDs.
- IRL and ERL are liquidity identities. IRL-to-ERL and ERL-to-IRL are candidate delivery models.
- SMT is shared context from S1. A model declares disabled, optional, required, or opposing-blocks policy.
- MMBM and MMSM may be directional models; MMXM may be a generalized framework. Source definitions decide.
- Unicorn and Breaker+FVG may be aliases. No second ID is allowed until a source comparison proves distinction.
- "Scalp", "swing", and Charter horizon labels are profiles, not strategies without materially distinct rules.

## Duplicate Resolution

1. Name a canonical owner and stable fact schema.
2. Freeze each legacy implementation and its consumers.
3. Add causal/parity fixtures at exact timestamps.
4. Adapt legacy output to the canonical schema without changing strategy behavior.
5. Migrate one consumer per authorized slice and compare candidate identities/geometry.
6. Deprecate only after manifests, evidence ledgers, Current Read, and BT2 adapters point to the new owner.

No coverage count may include advisor services, concepts, diagnostics, aliases, or placeholders as executable
strategies. No implementation or taxonomy status grants research validation, readiness, or execution authority.
