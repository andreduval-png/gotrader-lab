# I2 PO3 and CMD Comparison

Both use accumulation/consolidation, manipulation, distribution, and liquidity vocabulary. They are not behaviorally identical.

PO3 is a bidirectional canonical range lifecycle. CMD high-displacement v2 is an existing narrow short-only M5 profile with its own displacement freshness, FVG age, target, and RR gates. The legacy CMD candidate and frozen tests are unchanged. PO3 does not call or duplicate the CMD detector.

Result: shared conceptual vocabulary, distinct executable semantics. Merge and alias classification are rejected.
