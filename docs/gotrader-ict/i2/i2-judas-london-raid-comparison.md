# I2 Judas and London Raid Comparison

Shared facts: session window, liquidity, displacement, MSS, and potentially FVG. Shared semantic shape: session raid followed by reversal/expansion.

The existing Nasdaq London Raid / NY Reversal has a fixed London-to-New-York sequence and established entry/target behavior. Judas is described as an opening-context deceptive move but its session, open, reversal trigger, entry, and target are unresolved. It is therefore a distinct concept with substantial overlap, not a proven behavioral alias and not an executable model.

Duplicate registration is prevented. Existing London Raid v1/v2 behavior and identity remain unchanged. Judas is also distinct from Silver Bullet, whose one-hour windows and FVG retracement rules are already fixed.
