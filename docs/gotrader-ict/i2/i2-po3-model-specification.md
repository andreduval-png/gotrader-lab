# I2 Power of Three Model Specification

Identity: `ict_power_of_three_v1` version `1.0.0`, research-only. It supersedes the executable intent of legacy placeholder `amd_power_of_three_research_v1` without mutating that historical identity.

Accumulation is an active canonical `DEALING_RANGE`; no volatility threshold is invented. Manipulation is consumption of one canonical liquidity side linked to that range. Distribution is ordered displacement and MSS away from the consumed side. A same-direction FVG retrace creates entry eligibility; the manipulation extreme is invalidation and available opposite external liquidity is target.

The model is bidirectional. HOD/LOD is `po3_hod_lod_research_v1`, a profile changing objective policy rather than a duplicate detector. The base session policy accepts any canonical session and does not hardcode broker time.
