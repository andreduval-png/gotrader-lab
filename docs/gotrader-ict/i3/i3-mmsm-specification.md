# MMSM Specification

Strategy ID: `ict_market_maker_sell_model_v1`. Classification: experimental research-only.

MMSM is the exact bearish profile of the shared core unless a later source packet proves an asymmetry. It requires premium context in a named range, consumed external buy-side liquidity, bearish ERL-to-IRL transition and displacement, an eligible bearish PD array, and an available opposite external sell-side objective.

Entry is the immutable PD-array midpoint. Stop is the buy-side engineering extreme. Target is the named external sell-side objective. Optional S1 SMT may warn or block only through the frozen profile; it never moves geometry.
