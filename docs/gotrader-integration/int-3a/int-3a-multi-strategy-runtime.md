# INT-3A Multi-Strategy Runtime

The advisor now builds one compact canonical candidate collection containing
ICT 2022, PO3, and Judas alongside the existing IFVG v3 assessment.

Current Opportunity preserves candidate ID, strategy/version/profile, state,
context identity, blockers, and canonical geometry. Current Read reserves the
four integrated strategy families before compacting unrelated diagnostics.
Activate Market exports a list of owner-preserving candidate plans. The signal
contract carries the selected candidate and geometry identities only when an
unambiguous primary candidate exists.

The Operator Console renders each compact candidate separately. A candidate
without source-native geometry remains `NO_TRADE`; levels are never borrowed
from another strategy.
