# INT-3A ICT 2022 Integration

Status: integrated runtime research strategy, not research-validated.

`ict_2022_model_v1` consumes only canonical draw, liquidity, displacement,
MSS, and FVG facts. Its causal sequence is objective, opposing raid,
same-direction displacement, MSS, post-MSS FVG, and retracement.

Geometry ownership is source-native:

- entry: accepted post-MSS FVG midpoint retracement;
- stop: opposing raid extreme;
- target: the preselected primary external draw;
- conversion: `StrategyGeometryIntent` through G1.1 canonical geometry.

The model does not chase current price, alter the stop for R:R, or search for
a more favorable target. A consumed target, missed entry, or low native R:R
fails closed while preserving the native facts and geometry.

Authority remains none/none/none. `researchValidated` remains false.
