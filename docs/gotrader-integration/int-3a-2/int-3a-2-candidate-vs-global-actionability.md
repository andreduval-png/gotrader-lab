# Candidate vs Global Actionability

`OperatorCandidatePlanSummary` now carries two explicit fields:

- `candidateActionable`: the strategy produced complete, locally actionable canonical geometry.
- `globalActionable`: the unified set permits this candidate to become the singular global trade plan.

In opposing conflict both candidates are locally actionable, both are globally non-actionable, both display `NO_TRADE`, and neither becomes executable. This preserves strategy truth without weakening the global safety gate.
