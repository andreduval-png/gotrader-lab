# INT-1 IFVG v3/v4 Role Policy

- `ifvg_fresh_retest_v3_research`: authoritative current-market research strategy and Current Opportunity owner.
- `ifvg_fresh_retest_v4_candidate`: separate experimental research-only profile for forward validation.

Packets preserve strategy ID/version, profile ID/version, and parameter hash where applicable. V4 results cannot validate, replace, or silently inherit v3 identity. Frozen parameters were not changed by INT-1.
